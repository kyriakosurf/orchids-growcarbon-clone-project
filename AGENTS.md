## Project Summary
Grow Carbon is a global provider of regenerative infrastructure solutions. It focuses on connecting organic resource cycles through integrated environmental, biological, and digital technologies. The project aims to solve landfill saturation and soil degradation by building a distributed network of organic resource management hubs (Bio-HUBs).

## Tech Stack
- **Framework**: Next.js 15 (App Router, Turbopack)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Authentication**: Better-Auth (Infrastructure ready)
- **UI Components**: Shadcn UI (Radix based)

## Architecture
- `src/app/`: Contains the main routes.
  - `/`: Sleek landing and login entry page.
  - `/portal`: The main infrastructure and project details page (formerly the home page).
- `src/components/ui/`: Reusable UI components.

## User Preferences
- **Tone**: Professional, industrial, regenerative focus.
- **Theme**: Dark theme with high-contrast green accents.
- **Typography**: Bold, uppercase tracking, italic highlights.

## Project Guidelines
- Maintain the "Industrial Regeneration" aesthetic.
- Use `framer-motion` for smooth, staggered entries and micro-interactions.
- Keep the UI modular and highly visual with technical data points.

## Common Patterns
- **Hero Sections**: Large, bold typography with a "System Status" indicator.
- **Data Visualization**: Custom SVG-based motion paths and mono-spaced stat grids.
- **Cards**: Dark backgrounds with subtle gradients and border highlights on hover.
